## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара;
- `order.html` — оформление заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript (модальное окно и кнопка «Наверх»);
- `images/` — папка для изображений;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3 (переменные, Flexbox, Grid, БЭМ, позиционирование);
- JavaScript (базовая интерактивность);
- Git и GitHub.

## Самостоятельные доработки

В рамках выполнения КР №1 были добавлены следующие элементы:
- фиксированная кнопка «Наверх» (`position: fixed`);

- страница отдельного товара с таблицей характеристик;
